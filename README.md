# Projeto Integrador — Fundamentos de Engenharia de Software

## Nome do Sistema:
Sistema de Agendamento de Empréstimos de Carros

## Objetivo:
Propor e modelar um sistema para organizar o aluguel de veículos, permitindo o cadastro de carros e clientes, o controle da disponibilidade, o registro de aluguéis e devoluções e a consulta ao histórico de locações.

## Funcionalidades principais:
- Cadastro, consulta, atualização e remoção de veículos
- Consulta de carros disponíveis e indisponíveis
- Busca de veículos por ID ou placa
- Cadastro, consulta, atualização e remoção de clientes
- Busca de clientes por ID ou CPF
- Registro de aluguéis e devoluções
- Consulta de aluguéis ativos e histórico de locações
- Geração de relatórios

## Organização do projeto:
- 01-requisitos — stakeholders, levantamento de requisitos e regras de negócio
- 02-modelagem — diagramas e especificações dos casos de uso
- 03-arquitetura — visão arquitetural e projeto do sistema
- 04-verificacao-validacao — critérios de qualidade, verificação e validação
- 05-testes — planejamento e casos de teste
- 06-manutencao — evolução, análise de mudanças e riscos
- 07-entrega-final — documento final do projeto
